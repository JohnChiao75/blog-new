## 一、 启动器选择：开启方块世界的大门

Minecraft Java版必须通过启动器来启动游戏。你可以选择官方启动器，也可以选择功能更丰富的第三方启动器。

| 启动器类型 | 代表产品 | 核心特点 | 适用人群 |
| :--- | :--- | :--- | :--- |
| **官方启动器** | Minecraft Launcher | 由Mojang官方发布，界面简洁，可自动下载适配的Java环境，必须登录正版账号才能游玩 。 | 购买了正版游戏，且喜欢原汁原味体验的玩家。 |
| **第三方启动器** | **HMCL**、**PCL2**、**BakaXL** | 功能强大，支持**离线登录**、**多版本隔离**、**一键安装模组加载器**（如Forge、Fabric），下载速度更快 。 | 所有玩家，尤其是喜欢装模组、光影，或暂未购买正版的玩家。 |

对于大多数玩家，我个人强烈推荐使用**第三方启动器**，它们能极大简化安装模组和管理版本的过程。

## 二、 下载游戏：从零到一的安装流程

无论你选择哪款启动器，安装游戏版本的核心步骤都大同小异。这里以广受好评的 **PCL2 启动器** 为例进行演示 ：

1.  **获取启动器**：访问 PCL2 作者的发布页面（如爱发电）下载最新版本的压缩包，解压到你想存放游戏的文件夹（例如 `D:\Minecraft`）。
2.  **启动器初始化**：双击运行 `Plain Craft Launcher 2.exe`。
3.  **下载游戏版本**：
    *   在主界面点击“**下载**”选项卡。
    *   你会看到丰富的版本列表，包括**正式版**（如1.21.4、1.20.1）和**快照版**。新手建议选择最新的正式版或像1.20.1这样模组生态成熟的版本。
    *   选中版本后，点击右下角的“**开始安装**”。启动器就会自动从镜像源下载游戏核心文件 。

## 三、 选择登录方式：三种方式详解

Minecraft 提供了多种登录方式以适应不同玩家的需求。

### A. 购买正版：官方认证的完整体验

购买正版不仅能支持开发者，还能让你访问官方服务器，使用皮肤站等所有在线功能。

1.  **注册账号**：访问 Minecraft 官网，注册或登录你的**微软账号**。请注意，旧的 Mojang 账号已无法登录，必须迁移至微软账号 。
2.  **下单购买**：在官网使用支付宝支付。也可以选择从 Microsoft Store 或 Xbox 商店购买。
3.  **登录启动器**：在启动器中选择“**微软账号登录**”，按照提示在浏览器中完成授权即可。之后你的游戏库中就会显示 Minecraft Java版。

### B. 离线登录：免费尝鲜与局域网联机

离线登录允许你无需购买游戏即可进入游戏，非常适合想先体验一下，或者只和朋友在局域网内游玩的玩家 。

*   **操作方法**：在启动器的登录界面，选择“**离线模式**”（或“本地账户”），随意输入一个你想要的**游戏内名字**，点击登录即可 。
*   **局限性**：你无法加入需要正版验证的服务器，也无法在拥有正版验证的服务器上游玩，但使用第三方启动器的“开放局域网”功能与同样离线模式的朋友联机是完全没问题的。

### C. 外置登录：皮肤站与统一认证

外置登录主要用于连接第三方认证服务器，最常见的场景就是加入各种**皮肤站**（如 LittleSkin）或某些统一了账号系统的服务器 。

1.  **获取信息**：你需要从皮肤站或服务器管理员那里获得“**验证服务器 URL**”（Yggdrasil API 地址）和你的账号密码 。
2.  **在启动器中配置**：
    *   以 HMCL 为例，点击左下角的账户管理，选择“**添加认证服务器**”，输入从服务器获取的 URL。
    *   添加成功后，再选择“**添加外置登录账户**”，输入你在该皮肤站注册的用户名和密码 。
3.  **登录游戏**：选中刚刚添加的账户，即可使用你的皮肤站角色进入支持该外置登录的服务器。

## 四、 安装 Java 环境：为游戏提供运行基础

虽然官方和部分第三方启动器（如 PCL2）可以自动下载Java，但了解Java的安装和版本对应关系能帮你解决很多潜在问题 。

不同版本的 Minecraft 对 Java 版本有硬性要求，具体对照如下 ：

| 游戏版本 | 所需Java版本 |
| :--- | :--- |
| 1.6.1 至 1.16.5 | **Java 8** (推荐 1.8.0_51或更高) |
| 1.17 至 1.17.1 | **Java 16** |
| 1.18 至 1.20.4 | **Java 17** |
| 1.20.5 至 1.21.11 | **Java 21** |

**如何安装Java：**

1.  **下载**：访问 **Adoptium** 网站（Eclipse基金会提供的OpenJDK构建版），选择对应你操作系统和架构（通常选x64）的安装包下载 。
2.  **安装**：运行下载的 `.msi` 或 `.exe` 文件。在安装过程中，务必确保勾选 `Set JAVA_HOME environment variable` 选项，这能让系统正确找到Java 。
3.  **验证**：安装完成后，按下 `Win + R` 键，输入 `cmd` 打开命令提示符，输入 `java -version`。如果看到类似 `openjdk version "21.0.6"` 的输出，就说明Java安装成功了 。

## 五、 启动游戏与资源下载

### 启动游戏
一切准备就绪后，回到启动器主界面。确认左上角选择的游戏版本和账户无误后，点击“**启动游戏**”按钮。如果是首次启动，游戏还会下载一些必要的资源文件，请耐心等待 。

### 下载游戏资源（使用启动器）
大多数第三方启动器都内置了资源下载功能，这是最安全便捷的方式。
*   **模组**：在 PCL2 的“下载”页面中，切换到“**Mod**”或“**模组**”选项，即可搜索并下载与当前游戏版本兼容的模组。它会自动帮你区分 Forge 版和 Fabric 版 。
*   **整合包**：你可以在“下载”页面的“**整合包**”选项中，直接下载别人制作好的整合包，启动器会自动处理所有模组和配置。

### 下载游戏资源（使用网站）
如果你想寻找更丰富的资源，可以访问专业的 Minecraft 资源网站。
*   **推荐网站**：
    *   **CurseForge**：全球最大的模库，资源最全。
    *   **Modrinth**：新兴的开源模组平台，界面简洁，体验好 。
    *   **MC百科** ([mcmod.cn](https://mcmod.cn))：国内最全面的 Minecraft 百科网站，有详细的模组介绍和下载链接。
*   **手动安装方法**：下载后的模组文件通常是 `.jar` 格式。你需要打开游戏文件夹（在启动器设置中可以找到“打开游戏文件夹”的按钮），进入 `mods` 文件夹（如果没有就自己新建一个），将下载好的 `.jar` 文件复制进去。重启游戏，模组就会生效 。

## 六、 多人游戏：四种联机方式详解

和朋友联机是 Minecraft 最大的乐趣之一。这里有几种不同场景下的联机方式。

1.  **使用启动器联机（局域网联机）**
    *   **房主**：进入游戏，按 `ESC` 键，点击“**对局域网开放**”。你可以设置游戏模式和是否允许作弊。开放后，聊天栏会显示一个本地端口号（如 `25565`）。
    *   **朋友**：确保朋友和你连接在同一个路由器或Wi-Fi下。朋友在游戏主界面点击“**多人游戏**”→“**添加服务器**”，在服务器地址栏输入房主的**本机IP地址**（如 `192.168.1.5`）加上端口号，格式为 `192.168.1.5:25565`，即可加入 。

2.  **使用联机模组（如 Essential Mod）**
    *   **介绍**：Essential Mod 是一个强大的联机模组，它允许你直接邀请好友加入你的单人世界，无需端口转发，对网络要求较低。
    *   **方法**：房主和朋友都需要安装 Essential Mod。安装后，游戏内会多出一个好友系统和联机功能。你可以通过模组界面直接邀请好友加入你的游戏。

3.  **使用内网穿透（如 EasyTier / cpolar）**
    当你们不在同一个局域网，但又想联机时，就需要用到内网穿透技术。这种方法可以让你的电脑变成一个公网上的“服务器”。其核心原理是，通过内网穿透工具将你电脑上的游戏端口（默认25565）映射到一个公网地址上，朋友通过这个公网地址就能连接到你的电脑 。
    *   **以 EasyTier / cpolar 为例**：
        *   **房主**：在你电脑上运行 EasyTier 或 cpolar 客户端，创建一个隧道，将本地 Minecraft 游戏端口（如 `25565`）映射出去。工具会生成一个公网地址（如 `7.tcp.vip.cpolar.cn:12292`）。
        *   **配置游戏**：房主进入游戏并开放局域网。
        *   **朋友**：在游戏的多人在线界面，选择“直接连接”，输入房主通过穿透工具生成的**公网地址**，即可加入游戏 。

4.  **加入公共服务器**
    这是最简单的联机方式。你只需要找到一个心仪的服务器IP地址（例如知名的 Hypixel 服务器 `mc.hypixel.net`），然后在游戏主界面点击“**多人游戏**”→“**添加服务器**”，输入IP地址，即可加入成千上万人共同在线的世界。
